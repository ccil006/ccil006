# Carnet — suivi des sessions de formation

Petit outil en français pour saisir le nom d’une formation, sa date et le nombre de participants, puis ajouter ou supprimer des sessions dans un tableau.

## Ouvrir l’outil

[Essayer la démonstration en ligne](https://carnet-formations-cecile-271026.racing-ball-5053.chatgpt.site/)

Pour utiliser une copie sur votre ordinateur, téléchargez le fichier `index.html`, puis ouvrez-le dans votre navigateur. Tout le code et la présentation sont contenus dans ce fichier, sans installation nécessaire.

## Essayer

1. Quatre sessions fictives sont affichées au premier lancement.
2. Remplissez les trois cases et cliquez sur « Ajouter la session ».
3. La session apparaît dans le tableau et les totaux sont actualisés.
4. Cliquez sur la corbeille d’une ligne pour la supprimer.
5. Rechargez la page pour vérifier la conservation des changements.

## Conservation des données

Les changements sont conservés dans le navigateur utilisé, sur le même appareil, lorsque celui-ci autorise la conservation locale. Si celle-ci est indisponible, un message le signale. La suppression des données du navigateur peut effacer les sessions.

Les sessions ne sont pas partagées entre les visiteurs ou appareils. Les sessions saisies dans la démonstration en ligne ne sont pas incluses dans ce dépôt et ne sont pas transférées automatiquement à une copie téléchargée.
